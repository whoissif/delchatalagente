# Del chat al agente: IA para profesionales

Curso online en español para **profesionales que ya utilizan chats o bots de IA**. Explica, con ejemplos y prácticas guiadas, cómo un agente puede leer y modificar archivos, usar herramientas y trabajar dentro de límites definidos. No presupone experiencia en programación.

## Empieza aquí

Abre el **[curso interactivo](curso/index.html)** o la [portada visual](index.html). El recorrido dura unos 150 minutos y funciona en el navegador, sin instalación ni servicios externos. La búsqueda, los cuestionarios y el progreso se ejecutan localmente.

## Ruta de aprendizaje

1. **Entender:** del chat al agente y qué cambia cuando la IA puede actuar.
2. **Explorar:** herramientas, archivos, contexto, memoria y MCP, y cómo se traducen a Claude Code, Cowork, Codex y ChatGPT Work.
3. **Controlar:** permisos, sandbox y aprobaciones.
4. **Revisar:** comprobar el trabajo del agente antes de usarlo, con especial atención al análisis de datos, los modelos y los cálculos de ingeniería.

Las prácticas se basan en tareas con documentos y datos, transferibles a gestión, análisis y administración. El conjunto de datos del laboratorio es ficticio.

## Publicar

En GitHub, abre **Settings → Pages**, selecciona la rama principal y la carpeta raíz (`/(root)`). La portada `index.html` enlaza el curso y los materiales.

## Herramienta del laboratorio

Las prácticas usan **opencode** con modelos gratuitos (sin clave ni cuenta) como ejemplo concreto de harness; quien ya tenga suscripción puede usar Claude Code o Codex. La herramienta cambia con el tiempo; consulta su documentación (https://opencode.ai/docs) antes de usarla. No uses datos reales ni credenciales en los ejercicios.
