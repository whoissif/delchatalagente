# Acta de reunión de operaciones — Empresa Bruma

**Fecha:** 2 de junio de 2025  
**Asunto:** cierre de mayo y preparación del plan de junio  
**Nota:** escenario, personas, organización y datos completamente ficticios.

## Participantes

Representantes ficticios de producción, calidad, mantenimiento, planificación y almacén.

## Acuerdos

1. Planificación contrastará la disponibilidad real antes de proponer turnos adicionales para recuperar las 580 unidades de diferencia frente al plan de mayo.
2. Calidad revisará las 220 unidades pendientes de liberación final. Hasta entonces no se incluirán en las unidades disponibles para entrega.
3. Mantenimiento confirmará la calibración pendiente del manómetro del útil de prueba y verificará el sensor del transportador en la siguiente parada planificada.
4. Compras solicitará una fecha de suministro confirmada para el sensor S-04. Este acuerdo no autoriza emitir una orden de compra.
5. Operaciones contrastará el consumo nocturno del compresor con el registro de horas antes de atribuir la variación energética a una causa.
